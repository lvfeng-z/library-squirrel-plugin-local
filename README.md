# library-squirrel-plugin-local

[LibrarySquirrel](https://gitee.com/lv__feng/library-squirrel) 的本地导入插件（localImport）：从本地路径导入文件到资源库。

## 规则求值模型

规则求值自下而上、逐文件进行（反向于「先命中目录或序列实体、再覆盖其下所有文件」的常规心智）：不存在目录级或序列级的实体命中，每个文件各自按规则独立求值，实体的覆盖语义由这批逐文件结论汇出。

| | 常规心智（自上而下） | 实现（自下而上） |
|---|---|---|
| 目录规则 | 目录命中 → 递归覆盖其下所有文件 | 不存在目录级命中；每个文件向上回看**任一层**祖先目录名，命中即该文件命中 |
| 序列规则 | 序列 → 指向组成它的所有文件 | 每个文件按成员模板匹配，并向旁数**同目录同键**兄弟，计数≥下限（默认 2）才命中 |

边界注记：

- **规则两级类别**：规则顶层分两个综合类别——**元数据规则**（既有「条件行+元数据产出」路径的综合命名，条件行四种源、提取与合成原样，求值零改动；缺省类别，旧档与既有条目零迁移）｜**聚合规则**（轨行+作品标识声明+分轨入口，产出为聚合归属而非元数据声明）。四种条件源是两类共用的原料——聚合规则不发明选择器，轨行就是普通条件行（模板可带捕获，`{作品}` 为聚合标识专用中性取值词根）。聚合规则与组合引用（refs）、提取动作互斥（载入拒绝）；处置维度 `companionUse` 两值 `track`（本批唯一可写值）｜`metadata`（纯元数据承载，留位——档案载入即拒，编辑面不出选项）。
- **聚合段（标识等值并组）**：聚合不进逐文件求值循环——分组段与提取段对聚合规则整体跳过，轨行求值挂在汇流后的独立通道（与分组段同相位、居其后：群归属与元数据结论已定，聚合只消费既有结论不改写）。并组判定：各轨行命中文件按标识值相等归并=同一作品（文件名同名/序列群键/目录捕获共享三种成组形态同一语法；序列行=集合轨，整序列组 N 存储位）；必含轨所在行（角色在类型规约中 Min≥1）每组**恰一**命中才成立（≠1=歧义该组不成立，成员维持独立作品），主导文件=该唯一命中、作品键=`f:{主导文件相对路径}`；非必含轨行零命中=该轨缺席、作品仍成立；轨行间无且/或（平行选择器），作用域限定用轨行自身附加条件。规则间按档案序先到先得（文件已被在先规则归属不再改归属，歧义组成员仍可被后续规则接纳）。类型锚定：WorkType 选自 ListResourceTypes 注册表投影（插件轮级一次拉取）；引用的类型不在册（悬空）→档案载入停用该条目+告警、求值跳过。预置种子（视频+字幕→video、一图一文本→article）为普通聚合规则，首次档案初始化入档（来源=预置）与用户条目同权，「恢复预置」按 ID 补缺席兜底误删。快照 v3：`SnapFile` 增聚合归属三字段（`aggWorkKey`/`aggTrackRole`/`aggWorkType`=选中规则的声明作品类型，空=无聚合），旧快照读入按空聚合降级。
- **任一层祖先**：不限直接父目录——文件的祖先链上任意一层目录名命中即算。
- **层级锚「位于第 N 级」（目录行附加条件）**：不带锚时目录行默认任意祖先层；带锚则把命中层钉死为自识别根数起的第 N 级（根直下=第 1 级，N 复用 count 字段承载）——该级不存在即整行不中（严格不回退），深层/浅层同名形态不接管。「位于第 1 级」与父目录谓词（parentFormat/parentContains）互斥：第 1 级目录的上面是库根本身，组合恒不命中，保存期即拦（`rule_condition.go:417-432`）；N≥2 与父目录谓词合法共存。层级参照系=识别根（建会话时输入的库根，解析视图页头常驻显示）——同一规则换根会话求值层级随之平移；规则语言不含绝对路径。求值见 `rule_condition_subject.go:166-171`。
- **范围受求值面约束**：批量扫描清单或磁盘重扫，不在清单内的文件不求值。
- **落单出局**：{公共段}相同的成员不足下限的落单文件出局。
- **不跨目录、群卡归分组段**：序列不跨目录、成套文件的群卡呈现归分组段（分组段=判定文件归属哪个成套文件群的求值阶段；序列目标规则只写作用域内群组分析，群卡的规则归属在分组段，规则自身不因此产生文件级命中）。
- **组合之「之下不含其身」**：组合规则（refs 非空）以目录行为自身条件时，自身行锚定的目录不得同时是被引目录成员命中的目录——重合即整体不中（如「Artist 壳目录之下任意目录=作品集」的组合，壳目录自身不因其直属文件而成集）。纯门组合（无自身目录行）与自身行非目录形态（文件/序列行，无目录锚定）不受影响；被引成员为文件/序列形态时无目录命中层，亦不构成约束。
- **组合门段的成员命中层集合按锚定层口径**：门段登记被引目录成员「实际命中的层深集合」时读成员私有作用域的 DirHits——带层级锚的成员只登记第 N 级层，「之下不含其身」判定本身不变（`pipeline.go:444-450`、`pipeline.go:386-393`）。
- **执行调度多核化（语义模型不变）**：逐文件独立求值、群卡=群归属事实源、汇流点之后的全库面通道保持串行——语义照旧，仅执行调度使用多核：前置结构对齐按目录并行、结论循环按文件分块并行（结论按预分配切片下标写入，保输入序）；并行度=runtime.GOMAXPROCS(0)，取值集中于包内单一函数 `evalWorkerCount`（测试可覆写）；工作子 panic 沿串行同款冒泡，不引入 recover。
- **消费通道随 DirHit 天然贯穿（风险5 逐通道核验清单，2026-11-02）**：层级锚只在 N 级层记 DirHit，六路消费均「一致」并有锚测试——行包装并回（`rule_condition_eval.go:49`，`TestRowSubjectDirLevelHitMerge`）/ 提取「目录名（锚定命中层）」取最深（`rule_profile.go:339-345`，`TestExtractionAncestorDirRespectsDirLevelAnchor`）/ 组合门段成员命中层集合（`pipeline.go:444-450`，`TestRefGateMemberDirLevelAnchor`）/ 目录含义回放按命中层对照（`path_rule.go:240`，`TestDirMeaningReplayDirLevelAnchor`）/ 命中计数（`recognition.go:963-984`，`TestRuleStatsDirLevelAnchor`）/ 命中预览（`rules_preview.go:70-120`，`TestPreviewRuleDirLevelAnchor`）。组合规则直译句仅按成员目标类别成段、不含层级断言（`views/workbench/ruleFormModel.ts:577`），锚定成员的层级由成员自身摘要小字呈现（`ruleFormModel.ts:616`）——该呈现面无需改动。
- **旧档兼容**：旧版插件二进制载入含「位于第 N 级」词条的规则条目时，未知词条在档案载入校验被拒（`rule_condition.go:385-389`，与主体锚预留槽「载入即拒绝」同策略）；规则档案随插件二进制走、未上线不背历史债，未来若做规则导入导出须按词条集版本对齐。
- **泛化收紧的回归面（决策2）**：泛化器产出的目录条目从「子树同名都接管」收紧为「仅构造层级接管」——既有库深层同名目录重识别命中数下降属预期；既有会话的识别结果与新规则求值的差异会在增量识别/差异呈现面出现。
- **组界统一（剥壳的唯一组界定义）**：包裹组的组界只有一处定义——六对括号 `[]` / `【】` / `（）` / `()` / `「」` / `『』`（`structure_clue.go:319-321`），同对嵌套按最外层计、异对不干扰配对。剥壳变体（线索 `dirLevelStripped[n]` 等）由此派生：**首组内名**——`Artist[Isel]`→`Isel`、多组名 `[七尾ゆきじ] 酔いが…`→`七尾ゆきじ`（不再跨组取内名）；无括号组的 `Artist␣…` 空格前缀形态沿用原语义，不属组界。**规则侧剥壳语义由字面括号模板承载**：目录行写 `[{标签}]{任意}` 即取首组内名（多组名取首组内名、尾段由 `{任意}` 吞掉；单组整名 `[路灯后辈]` 尾段为空亦命中），编辑器词条表内有同名例子。提取动作上的旧 strip 前后缀已废弃：旧档案载入即迁移——裸单占位词模板 + 配对括号前后缀等价改写为 `开括号{词}闭括号{任意}`，其余组合丢弃剥壳并在规则描述留迁移注记。
- **重复段记号 `{词+}` / `{词*}` / `{词+;分隔}`**：占位词可带量词——`+`=单元至少一次、`*`=可零次（零值零声明），`;分隔`=单元间强制出现该字面（缺省=可选空白）。词位仅 标签/作者/集名（`rule_condition.go:255`，其他词根带量词即校验拒绝）。**重复单元边界**：前字面段收尾为开括号且后字面段起首为配对闭括号→单元=`[开括号 捕获 闭括号]`（包裹单元，如 `[{标签+}]`）；否则单元=词本身（裸词，必须显式 `;分隔`——无包裹边界时缺省切分不可判定）。多值通路=整段编为恰一个位置捕获组 + 绑定层按单元子模式扇出多条绑定（`rule_condition_subject.go:418`）+ 提取层按名取全部绑定逐条产声明；量词下命名组只留末次匹配，故不采命名组套量词路线。**三面引用禁区（when 生效条件/值校验/组合接线）**：这些消费面按一名一值取值、多值喂入会静默只取末值——重复段词仅提取扇出可消费，三面选择不到、JSON 硬写报统一中文错误（`rule_condition.go:292-298`，前端下拉镜像 `ruleFormModel.ts:431`）。
- **可选记号 `{字面?}` / `{词?}`**：`?` 后缀两形态——`{字面?}`=可选分隔字面（如 `[{作者}]{ ?}{集名}` 一条规则通吃有无空格两形态，编译 `(?:字面)?`）；`{词?}`=可选词位（单值 0..1 次，包裹判定命中时整组同进退——`[{作者?}]` 的开括号/闭括号随词同缺席，不产空括号命中，`rule_condition.go:653-676`）。**位置约束**：可选分隔的左邻与右邻中至少一侧须为非空必选字面段或模板首/尾，占位词（含可选词位、重复段组）不作锚、相邻两可选分隔互不作锚（`rule_condition.go:351-361`）——两取值词之间的可选分隔在无分隔形态下切分位置任意，保存期即拒。**序列成员模板**不支持可选词位（与重复段同口径，`rule_condition.go:639-641`）；可选分隔字面不受此限。**缺席=无绑定**：绑定层对未参与本次匹配的命名组跳过绑定登记（`rule_condition_subject.go:418`），下游全按既有「取不到值」语义——提取 FromCapture 零声明、值校验门为假、when 条件不成立、组合接线（refCapture 限定名）无声明；参与匹配但捕获空串的组照常登记。**与 `{词*}` 的引用权分工**：`?` 走普通命名组通路、三面引用（when/值校验/组合接线）可用；`*` 走多值通路、三面禁区——次数轴 `+`/`*`/`?` 三档正交。**已知边界**：0+ 包裹重复组后接可选分隔（如 `[{标签*}]{ ?}{标题}`）时闭括号被收进可缺形态、左邻无必选字面锚，按位置约束拒绝（放宽是纯加法）。**两域缺席语义分叉**：模板域缺席=无绑定；手写 JSON 原生正则域（`RegexPattern.matchWithCaptures`，`rule_pattern.go:108-133`）沿用历史空串绑定，不改。
- **同占位词多次出现（位次分立）**：标签/作者/集名 三词位可在同一模板多次出现，裸写即可——按出现序（`tokenizeCondx` 从左到右，普通词/可选词位/重复段变体统一计数）自动编号，无新书写记号；`{标签2}` 仍是词表外报错、不解析为位次，其余词根双出现维持「模板占位词 {词} 重复」拒绝。**位次=组名后缀与寻址键**：位1 保持裸组名（`tag`，存量单出现模板与旧档零变化），位 N≥2 组名=双下划线后缀（`tag__2`）；提取行 `captureName` 写位次名即取该位绑定（重复段位逐值扇出多声明），when 自有名与组合接线限定名「成员ID.rN.组名」同样按位次名寻址，`#canon` 规范名键随位次名、位间不互扰。**三面禁引按位**：when 生效条件/值校验/组合接线三面对位判定——位为重复段（多值产出）则该位禁引（引用取不到值=不成立/零产出，JSON 硬写报统一中文错误、文案按词根中文渲染），位为单值词（含可选词位）可引用。**值校验位次化**：值校验可挂位≥2（`occur` 字段；相等类别的对方词另有 `againstOccur`），位1 缺省=存量档案零变化。**位次漂移注意**：在已有出现之前插入同词根新出现会使后续位次整体 +1——旧 `tag__2` 仍存在但指向新插入处，存在性检查不报警、静默语义漂移，编辑模板后须复核引用了受影响位次名的提取/when/值校验/接线配置行。**与重复段记号正交**：多次出现 × 裸词/包裹/可选词位/重复段 `{词+}`/`{词*}`/`{词+;分隔}` 全组合合法、位次独立编号（`{标签}`×2+`{标签+}` 三处各自成位）。
- **填充段惰性化（2026-11-04 决策4）**：无类锚定的贪婪填充段（值类词 default `.+` 分支与中位 `{任意}` 吞位段）一律编译为惰性 `.+?`、让位一切占位词——leftmost-first 下惰性段取最短，后邻类词/重复段先取得满足位（`rule_condition.go:379-383`）；类锚定段不动（数字类/括号排除类/重复段位置组保持类内最大）。括号包裹的 `{任意}` 编译为排除配对闭括号的非空类（括号字面为锚、通配段不跨括号组吞并，前邻惰性 span 赖此收界）。存量切分语义允许变化（含 `_` 分隔模板首/尾段取舍、canon 载体切分），验收由 live-test diff 归因附记承载而非存量指纹不变闸。
- **快照求值器身份**：`RecognitionSnapshot.EvaluatorBuildID`（`recognition.go:586`，=自身插件清单 buildId，空串=未打标构建）铸入每份识别快照，参与两道闸——增量闸：mtime 游标复用须求值器身份等值（`recognition.go:2302-2310`）；激活对账：快照铸于另一构建标识的求值器即提示重新识别（`session.go:930-934`），未打标构建不参与比对、旧快照空串而当前有值按换版处理。buildId 内容化（`build.ps1`）：干净树=git describe，dirty 树附 dist 载荷摘要前 8 位——不同产物必不同身份，识别内核随构建演进后旧结论自动失去游标复用资格。

### 基目录刻画三式

一处目录若要被规则精确刻画为「基目录」，现有三式按代价递增：**层级锚**=识别根参照系（附加条件「位于第 N 级」，位置类信息的最简表达，覆盖「第一层子目录=标签」这类实例）/ **父目录名锚**=既有谓词（parentFormat / parentContains，按名字锁定上级）/ **条件间引用**=ref 预留槽二期（`rule_condition.go:144-154` 预留、载入即拒绝）——仅当需要「跨条件引用对方行的值」时才需启用 ref；位置与父名已能刻画基目录时不必等待 ref。

## 本地导入工作台（骨架期）

- **创建入口三分支**（`work_fetch.go` `CreateWithHeartbeat`）：宿主新建任务输本地路径后——库根命中既有解析会话→意图信号「转入解析」零任务收尾；无会话→Create 流内弹「开始解析（默认）/取消」确认弹窗（等待期经 `HeartbeatCreateFetcher` 心跳保活，插件侧 5 分钟超时=取消，两态均以意图信号收尾，零任务零落库）；工作台发起的创建（会话带发起标记）→过滤产出分支（选择集过滤属后续阶段）。
- **会话管理器**（`session.go`）：会话=按库根持久化工件，三件套布局——meta 键 `workbench-session:<库根标识>` 值=信封 JSON `{v,session,shardSet,shards,codec,digest}`（轻字段+载荷簿记，shardSet 恒在场=新旧格式探测判据，schemaVersion 自管）；分片键 `workbench-session-snap:<库根标识>@{批次号}#{i}`，值=重载荷（Snapshot/LastDiff）gzip 压缩后的 base64 文本，单片最终值 ≤3MB；索引键 `workbench-session-index`=归一化库根升序数组（缺失/损坏回退全量扫描重建）；保存分轻/全双入口（唯一全保存入口=`CompleteRecognitionWithDiff` 识别完成落库，赋值/确认/选择集等会话级变更轻保存只写 meta、载荷留在分片），旧「单键单 JSON」格式兼容可读、读到即转新格式；同库根至多一活动会话，跨重启恢复；档案写（泛化/裁决生成/规则编辑面三入口）与会话写一律经会话管理器单点串行；恢复会话时做规则档案与求值器身份对账（档案被外部变更、或快照铸于另一构建标识的求值器——快照带 `evaluatorBuildId` 字段——则提示重新识别；未打标构建〔标识空串〕不参与比对，旧快照空串而当前有值按换版处理）。
- **前端事件协议**：`plugin:local-import:workbench:{request|response|event}` 族，请求带序号配对（`frontend/src/workbench/` 入口 + `views/workbench/` 组件，经既有 Vite 预编译管线构建为多页面产物）。
- **页面声明**（`plugin.json`，契约 18）：`workbench` 一级页面（会话列表）+ 侧栏菜单 + `workbench-parse` 二级解析页面（`content.parent`；双栏工作区——左栏识别全景清单与筛选，右栏解析面板 `ParsePanel.vue` 承载单次赋值/泛化成规则/冲突裁决）+ 其两个子页（规则管理、解析观测〔「建设中」挂载位〕）+ 入口确认弹窗 dialog。解析视图头部另设「规则管理」「解析观测」直链。
