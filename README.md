# library-squirrel-plugin-local

[LibrarySquirrel](https://gitee.com/lv__feng/library-squirrel) 的本地导入插件（localImport）：从本地路径导入文件到资源库。

## 规则求值模型

规则求值自下而上、逐文件进行（反向于「先命中目录或序列实体、再覆盖其下所有文件」的常规心智）：不存在目录级或序列级的实体命中，每个文件各自按规则独立求值，实体的覆盖语义由这批逐文件结论汇出。

| | 常规心智（自上而下） | 实现（自下而上） |
|---|---|---|
| 目录规则 | 目录命中 → 递归覆盖其下所有文件 | 不存在目录级命中；每个文件向上回看**任一层**祖先目录名，命中即该文件命中 |
| 序列规则 | 序列 → 指向组成它的所有文件 | 每个文件按成员模板匹配，并向旁数**同目录同键**兄弟，计数≥下限（默认 2）才命中 |

边界注记：

- **任一层祖先**：不限直接父目录——文件的祖先链上任意一层目录名命中即算。
- **层级锚「位于第 N 级」（目录行附加条件）**：不带锚时目录行默认任意祖先层；带锚则把命中层钉死为自识别根数起的第 N 级（根直下=第 1 级，N 复用 count 字段承载）——该级不存在即整行不中（严格不回退），深层/浅层同名形态不接管。「位于第 1 级」与父目录谓词（parentFormat/parentContains）互斥：第 1 级目录的上面是库根本身，组合恒不命中，保存期即拦（`rule_condition.go:417-432`）；N≥2 与父目录谓词合法共存。层级参照系=识别根（建会话时输入的库根，解析视图页头常驻显示）——同一规则换根会话求值层级随之平移；规则语言不含绝对路径。求值见 `rule_condition_subject.go:166-171`。
- **范围受求值面约束**：批量扫描清单或磁盘重扫，不在清单内的文件不求值。
- **落单出局**：{公共段}相同的成员不足下限的落单文件出局。
- **不跨目录、群卡归分组段**：序列不跨目录、成套文件的群卡呈现归分组段（分组段=判定文件归属哪个成套文件群的求值阶段；序列目标规则只写作用域内群组分析，群卡的规则归属在分组段，规则自身不因此产生文件级命中）。
- **组合之「之下不含其身」**：组合规则（refs 非空）以目录行为自身条件时，自身行锚定的目录不得同时是被引目录成员命中的目录——重合即整体不中（如「Artist 壳目录之下任意目录=作品集」的组合，壳目录自身不因其直属文件而成集）。纯门组合（无自身目录行）与自身行非目录形态（文件/序列行，无目录锚定）不受影响；被引成员为文件/序列形态时无目录命中层，亦不构成约束。
- **组合门段的成员命中层集合按锚定层口径**：门段登记被引目录成员「实际命中的层深集合」时读成员私有作用域的 DirHits——带层级锚的成员只登记第 N 级层，「之下不含其身」判定本身不变（`pipeline.go:444-450`、`pipeline.go:386-393`）。
- **执行调度多核化（语义模型不变）**：逐文件独立求值、群卡=群归属事实源、汇流点之后的全库面通道保持串行——语义照旧，仅执行调度使用多核：前置结构对齐按目录并行、结论循环按文件分块并行（结论按预分配切片下标写入，保输入序）；并行度=runtime.GOMAXPROCS(0)，取值集中于包内单一函数 `evalWorkerCount`（测试可覆写）；工作子 panic 沿串行同款冒泡，不引入 recover。
- **消费通道随 DirHit 天然贯穿（风险5 逐通道核验清单，2026-11-02）**：层级锚只在 N 级层记 DirHit，六路消费均「一致」并有锚测试——行包装并回（`rule_condition_eval.go:49`，`TestRowSubjectDirLevelHitMerge`）/ 提取「目录名（锚定命中层）」取最深（`rule_profile.go:339-345`，`TestExtractionAncestorDirRespectsDirLevelAnchor`）/ 组合门段成员命中层集合（`pipeline.go:444-450`，`TestRefGateMemberDirLevelAnchor`）/ 目录含义回放按命中层对照（`path_rule.go:240`，`TestDirMeaningReplayDirLevelAnchor`）/ 命中计数（`recognition.go:963-984`，`TestRuleStatsDirLevelAnchor`）/ 命中预览（`rules_preview.go:70-120`，`TestPreviewRuleDirLevelAnchor`）。组合规则直译句仅按成员目标类别成段、不含层级断言（`views/workbench/ruleFormModel.ts:577`），锚定成员的层级由成员自身摘要小字呈现（`ruleFormModel.ts:616`）——该呈现面无需改动。
- **旧档兼容**：旧版插件二进制载入含「位于第 N 级」词条的规则条目时，未知词条在档案载入校验被拒（`rule_condition.go:385-389`，与主体锚预留槽「载入即拒绝」同策略）；规则档案随插件二进制走、未上线不背历史债，未来若做规则导入导出须按词条集版本对齐。
- **泛化收紧的回归面（决策2）**：泛化器产出的目录条目从「子树同名都接管」收紧为「仅构造层级接管」——既有库深层同名目录重识别命中数下降属预期；既有会话已识别结论与新规则求值的差异会在增量识别/差异呈现面出现。
- **剥壳表现况**：内置剥壳表三条——`Artist[...]`、`Artist␣...`、`[...]` 裸括号（`structure_clue.go:54-58`）；表序在前者优先，`Artist[...]` 先配、裸括号兜底，无冲突。

### 基目录刻画三式

一处目录若要被规则精确刻画为「基目录」，现有三式按代价递增：**层级锚**=识别根参照系（附加条件「位于第 N 级」，位置类信息的最简表达，覆盖「第一层子目录=标签」这类实例）/ **父目录名锚**=既有谓词（parentFormat / parentContains，按名字锁定上级）/ **条件间引用**=ref 预留槽二期（`rule_condition.go:144-154` 预留、载入即拒绝）——仅当需要「跨条件引用对方行的值」时才需启用 ref；位置与父名已能刻画基目录时不必等待 ref。

## 本地导入工作台（骨架期）

- **创建入口三分支**（`work_fetch.go` `CreateWithHeartbeat`）：宿主新建任务输本地路径后——库根命中既有解析会话→意图信号「转入解析」零任务收尾；无会话→Create 流内弹「开始解析（默认）/取消」确认弹窗（等待期经 `HeartbeatCreateFetcher` 心跳保活，插件侧 5 分钟超时=取消，两态均以意图信号收尾，零任务零落库）；工作台发起的创建（会话带发起标记）→过滤产出分支（选择集过滤属后续阶段）。
- **会话管理器**（`session.go`）：会话=按库根持久化工件，三件套布局——meta 键 `workbench-session:<库根标识>` 值=信封 JSON `{v,session,shardSet,shards,codec,digest}`（轻字段+载荷簿记，shardSet 恒在场=新旧格式探测判据，schemaVersion 自管）；分片键 `workbench-session-snap:<库根标识>@{批次号}#{i}`，值=重载荷（Snapshot/LastDiff）gzip 压缩后的 base64 文本，单片最终值 ≤3MB；索引键 `workbench-session-index`=归一化库根升序数组（缺失/损坏回退全量扫描重建）；保存分轻/全双入口（唯一全保存入口=`CompleteRecognitionWithDiff` 识别完成落库，赋值/确认/选择集等会话级变更轻保存只写 meta、载荷留在分片），旧「单键单 JSON」格式兼容可读、读到即转新格式；同库根至多一活动会话，跨重启恢复；档案写（泛化/裁决生成/规则编辑面三入口）与会话写一律经会话管理器单点串行；恢复会话时做规则档案对账（档案被外部变更则提示重新识别）。
- **前端事件协议**：`plugin:local-import:workbench:{request|response|event}` 族，请求带序号配对（`frontend/src/workbench/` 入口 + `views/workbench/` 组件，经既有 Vite 预编译管线构建为多页面产物）。
- **页面声明**（`plugin.json`，契约 18）：`workbench` 一级页面（会话列表）+ 侧栏菜单 + `workbench-parse` 二级解析页面（`content.parent`；双栏工作区——左栏识别全景清单与筛选，右栏解析面板 `ParsePanel.vue` 承载单次赋值/泛化成规则/冲突裁决）+ 其两个子页（规则管理、解析观测〔「建设中」挂载位〕）+ 入口确认弹窗 dialog。解析视图头部另设「规则管理」「解析观测」直链。
