# library-squirrel-plugin-local

[LibrarySquirrel](https://gitee.com/lv__feng/library-squirrel) 的本地导入插件（localImport）：从本地路径导入文件到资源库。

## 规则求值模型

规则求值自下而上、逐文件进行（反向于「先命中目录或序列实体、再覆盖其下所有文件」的常规心智）：不存在目录级或序列级的实体命中，每个文件各自按规则独立求值，实体的覆盖语义由这批逐文件结论汇出。

| | 常规心智（自上而下） | 实现（自下而上） |
|---|---|---|
| 目录规则 | 目录命中 → 递归覆盖其下所有文件 | 不存在目录级命中；每个文件向上回看祖先目录链，按目录行模板逐层求值（单段=任一层命中即中，多段模板=整条层级链须成立），任一行命中即该文件命中 |
| 序列规则 | 序列 → 指向组成它的所有文件 | 每个文件按成员模板匹配，并向旁数**同目录同键**兄弟，计数≥下限（默认 2）才命中 |

边界注记：

- **规则两级类别**：规则顶层分两个综合类别——**元数据规则**（既有「条件行+元数据产出」路径的综合命名，条件行四种源、提取与合成原样，求值零改动；缺省类别，旧档与既有条目零迁移）｜**聚合规则**（轨行+作品标识声明+分轨入口，产出为聚合归属而非元数据声明）。四种条件源是两类共用的原料——聚合规则不发明选择器，轨行就是普通条件行（模板可带捕获，`{作品标识}` 为聚合标识专用中性取值词根，旧词 `{作品}` 为其别名书写）。聚合规则与提取动作互斥、轨行不得携带作用域附件（载入拒绝）；处置维度 `companionUse` 两值 `track`（本批唯一可写值）｜`metadata`（纯元数据承载，留位——档案载入即拒，编辑面不出选项）。
- **聚合段（标识等值并组）**：聚合不进逐文件求值循环——分组段与提取段对聚合规则整体跳过，轨行求值挂在汇流后的独立通道（与分组段同相位、居其后：群归属与元数据结论已定，聚合只消费既有结论不改写）。并组判定：各轨行命中文件按标识值相等归并=同一作品（文件名同名/序列群键/目录捕获共享三种成组形态同一语法；序列行=集合轨，整序列组 N 存储位）；必含轨所在行（角色在类型规约中 Min≥1）每组**恰一**命中才成立（≠1=歧义该组不成立，成员维持独立作品），主导文件=该唯一命中、作品键=`f:{主导文件相对路径}`；非必含轨行零命中=该轨缺席、作品仍成立；轨行间无且/或（平行选择器），作用域限定用轨行自身附加条件。规则间按档案序先到先得（文件已被在先规则归属不再改归属，歧义组成员仍可被后续规则接纳）。类型锚定：WorkType 选自 ListResourceTypes 注册表投影（插件轮级一次拉取）；引用的类型不在册（悬空）→档案载入停用该条目+告警、求值跳过。预置种子（视频+字幕→video、一图一文本→article）为普通聚合规则，首次档案初始化入档（来源=预置）与用户条目同权，「恢复预置」按 ID 补缺席兜底误删。快照 v3：`SnapFile` 增聚合归属三字段（`aggWorkKey`/`aggTrackRole`/`aggWorkType`=选中规则的声明作品类型，空=无聚合），旧快照读入按空聚合降级。
- **任一层祖先**：不限直接父目录——文件的祖先链上任意一层目录名命中即算。
- **多段目录模板（层级写进格式）**：目录条件行的整条模板可写多段——`段1/段2`（`/`=紧邻、`//`=之下任意层、`/{N}`=显式层距 N≥1；首段前/末段后不得有分隔符、空段拒绝）。求值逐段推导、候选落地层自深向浅（最具体优先）——末段落于某层后，其余段自落地层向上按段距放链，全部段与终结谓词成立才命中，DirHit 记落地段层一条（`rule_condition_subject.go:319-347`）。捕获按段绑定、同一占位词跨段出现按整条模板出现序连续编号（位次寻址 `rN.组名__M` 不变）。文件行/序列行模板与 contains 问法含 `/` 保存期拒绝（`rule_condition.go:1077-1100`）；单段模板走现行路径零变化。
- **范围受求值面约束**：批量扫描清单或磁盘重扫，不在清单内的文件不求值。
- **落单出局**：成套键相同的成员不足下限的落单文件出局（成套键=成员模板全部非序号必选捕获按序拼接，见下方「词表重设计」注记）。
- **不跨目录、群卡归分组段**：序列不跨目录、成套文件的群卡呈现归分组段（分组段=判定文件归属哪个成套文件群的求值阶段；序列目标规则只写作用域内群组分析，群卡的规则归属在分组段，规则自身不因此产生文件级命中）。
- **作用域附件（位于此目录下）**：目录行专属附加条件 `refScope`——选一个来源（「库根」或一条供给方规则）加层距（0=任意深度、1=紧邻缺省、N≥2 显式隔 N 级；N=0 是附件的合法哨兵，与模板段距不同）。库根来源（`Value="$root"` sentinel）：无供给方求值与悬空，门段恒注入命中层集 {−1}，同一层距阶梯算术即得绝对层级语义——紧邻=根直下第 1 级、隔 N=自根数起第 N 级、任意=恒成立（补回 dirLevel 退役后的绝对层级表达）。供给方=纯目录规则（全部条件行含括号子组递归目标=目录；定群/聚合排除），独立成规则、自身产元数据，改一处即联动。求值门段先行：对全部启用规则条件行递归扫描附件，供给方按依赖拓扑序求值（供给方自身可携带任意作用域附件〔规则来源或库根〕，链上供给方先于下游求值；库根哨兵不构成依赖边），登记命中层集与限定键捕获快照（`pipeline.go:437-533`）；层距阶梯判据=候选层 c 合格 ⟺ ∃D∈供给方命中层集 s.t. 层距 0 时 c>D、层距 N 时 c−D=N（`rule_condition_subject.go:177-200`）——其身与「消费层在供给方之上」天然不可成立；四通道（提取 / 目录含义回放 / 命中预览 / 单文件重算）各自逐文件过同一门段，链式与层距语义一致、无特例分支。链上任一级未命中（停用/悬空/被跳过）→ 该级层集缺席 → 下级行不中（严格语义逐级传递，不降级；供给方引用链深度不设上限）。保存期校验五则：自引用/悬空/成环/聚合互斥（聚合轨行禁附件）/重复段接线——全档案供给方引用链无环即可（自引用=深度 1 的环，仍按自引用文案拒绝；库根哨兵不构成依赖边），成环在保存/载入同管线拒绝并点名环路路径「作用域附件引用的供给方链成环（A → B → … → A）」；库根 sentinel 对五则与供给方合格性全放行（非供给方形态、无捕获与层集求值可判）；供给方悬空条目载入跳过+告警。refCapture 提取与 when 限定名的限定键通道经附件保留（注入消费规则私有作用域）。
- **执行调度多核化（语义模型不变）**：逐文件独立求值、群卡=群归属事实源、汇流点之后的全库面通道保持串行——语义照旧，仅执行调度使用多核：前置结构对齐按目录并行、结论循环按文件分块并行（结论按预分配切片下标写入，保输入序）；并行度=runtime.GOMAXPROCS(0)，取值集中于包内单一函数 `evalWorkerCount`（测试可覆写）；工作子 panic 沿串行同款冒泡，不引入 recover。
- **多段命中层随 DirHit 贯穿（自决6 六路消费核验清单，2026-11-17）**：多段目录行只在落地段层记 DirHit 一条、「取最深」语义自然对齐——行包装并回（`rule_condition_eval.go:52`）/ 提取「目录名（命中层）」取最深（`rule_profile.go:349-354`，`LastDirHit` 见 `rule_context.go:166-176`）/ 作用域附件供给方命中层集登记（`pipeline.go:518-523`）/ 目录含义回放按命中层对照（`path_rule.go:234-237`）/ 规则命中计数（`recognition.go:1396-1406`）/ 命中预览（`rules_preview.go:76-128`）——六路均按 DirHit 单一口径消费，无分叉。
- **旧档兼容**：档案结构版本 v5——多段模板与作用域附件写法旧二进制接不住（多段模板在旧版是词法合法却永不命中的静默死形态），故整体升版：新二进制双读 v4/v5（v4 档照常读入，其内 refs 非空条目跳过+告警，保存归一 v5）；旧二进制读 v5 经既有版本闸整体拒载、重置并原文备份单代。v4 档携带「位于第 N 级」词条（dirLevel）的条目按未知词条先例载入即拒（`rule_condition.go:1157-1161`）——跳过+告警，须以多段模板或普通目录行重建。规则档案随插件二进制走、未上线不背历史债，未来若做规则导入导出须按词条集版本对齐。
- **泛化收紧的回归面（决策2）**：泛化器产出的目录层多段模板从「子树同名都接管」收紧为「整条构造层级链接管」——既有库深层同名目录重识别命中数下降属预期；既有会话的识别结果与新规则求值的差异会在增量识别/差异呈现面出现。
- **组界统一（剥壳的唯一组界定义）**：包裹组的组界只有一处定义——六对括号 `[]` / `【】` / `（）` / `()` / `「」` / `『』`（`structure_clue.go:318-321`），同对嵌套按最外层计、异对不干扰配对。剥壳变体（线索 `dirLevelStripped[n]` 等）由此派生：**首组内名**——`Artist[Isel]`→`Isel`、多组名 `[七尾ゆきじ] 酔いが…`→`七尾ゆきじ`（不再跨组取内名）；无括号组的 `Artist␣…` 空格前缀形态沿用原语义，不属组界。**规则侧剥壳语义由字面括号模板承载**：目录行写 `[{标签}]{任意}` 即取首组内名（多组名取首组内名、尾段由 `{任意}` 吞掉；单组整名 `[路灯后辈]` 尾段为空亦命中），编辑器词条表内有同名例子。提取动作上的旧 strip 前后缀已废弃：旧档案载入即迁移——裸单占位词模板 + 配对括号前后缀等价改写为 `开括号{词}闭括号{任意}`，其余组合丢弃剥壳并在规则描述留迁移注记。
- **词表重设计（占位词词汇表，2026-11-15）**：五面变化——①{作品} 改名 **{作品标识}**（含义不明、与「一件作品」撞名；英文组名 `work` 不变、存量档案零迁移，旧词 `{作品}` 为别名合法书写、显示与保存归一为新词）；②新增 **{描述}** 词（作品描述维度取值词：提取动作接「描述」维度，创建期接线 `site_work_description`，多值取首个——与标题取首同语义）；③{作品号}/{序号} 放宽**字母数字类**（`[0-9A-Za-z]+`：纯数字照常命中、BV 号一类字母混合编号整词可匹配；{日期} 维持纯数字类）；④**多处出现开放到全部取值词**（标签/作者/集名/标题/序号/作品号/日期/作品标识/描述 九词根各处独立取值、位≥2 组名 `en__N`，见下方「同占位词多次出现」注记）；⑤序列模板**解禁可选词位**（决策6，见「可选记号」注记）。**{公共段} 说明如实化**（名字保留）：它是公共部分**白段词**——不接任何元数据维度、只圈住公共部分文本（仅序列模板、单次、不可带问号）；成套判断的键其实是「**全部非序号必选捕获按序拼接**」（可选捕获不进键）——`{公共段}` 只是圈段的白段词，键的真正来源是模板里全部非序号捕获本身。{作品标识} 与 {作品号} 同模板并用拒绝（整词标识 vs 编号段语义近邻防混用）。
- **重复段记号 `{词+}` / `{词*}` / `{词+;分隔}`**：占位词可带量词——`+`=单元至少一次、`*`=可零次（零值零声明），`;分隔`=单元间强制出现该字面（缺省=可选空白）。词位仅 标签/作者/集名（`rule_condition.go:282-287`，其他词根带量词即校验拒绝）。**重复单元边界**：前字面段收尾为开括号且后字面段起首为配对闭括号→单元=`[开括号 捕获 闭括号]`（包裹单元，如 `[{标签+}]`）；否则单元=词本身（裸词，必须显式 `;分隔`——无包裹边界时缺省切分不可判定）。多值通路=整段编为恰一个位置捕获组 + 绑定层按单元子模式扇出多条绑定（`rule_condition_subject.go:629-660`）+ 提取层按名取全部绑定逐条产声明；量词下命名组只留末次匹配，故不采命名组套量词路线。**三面引用禁区（when 生效条件/值校验/作用域接线）**：这些消费面按一名一值取值、多值喂入会静默只取末值——重复段词仅提取扇出可消费，三面选择不到、JSON 硬写报统一中文错误（`rule_condition.go:320-332`，前端下拉镜像 `ruleFormModel.ts:1233-1240`）。
- **可选记号 `{字面?}` / `{词?}`**：`?` 后缀两形态——`{字面?}`=可选分隔字面（如 `[{作者}]{ ?}{集名}` 一条规则通吃有无空格两形态，编译 `(?:字面)?`）；`{词?}`=可选词位（单值 0..1 次，包裹判定命中时整组同进退——`[{作者?}]` 的开括号/闭括号随词同缺席，不产空括号命中，`rule_condition.go:747-808`）。**位置约束**：可选分隔的左邻与右邻中至少一侧须为非空必选字面段或模板首/尾，占位词（含可选词位、重复段组）不作锚、相邻两可选分隔互不作锚（`rule_condition.go:416-432`）——两取值词之间的可选分隔在无分隔形态下切分位置任意，保存期即拒。**序列成员模板**解禁可选词位（2026-11-15 决策6）：可选捕获**不进成套键**——逐件变化段（如分P 的 P标题）写 `{标题?}` 即可捕获、可提取、不拆套；缺席该段的成员照常入套（该词无绑定无声明）；`{公共段?}` 维持拒绝（成群依据不可缺席）；全可选（空键）模板拦截新存档（同尾缀异名文件会误并套，存量照旧）；可选分隔字面不受限。**缺席=无绑定**：绑定层对未参与本次匹配的命名组跳过绑定登记（`rule_condition_subject.go:629-660`），下游全按既有「取不到值」语义——提取 FromCapture 零声明、值校验门为假、when 条件不成立、作用域接线（refCapture 限定名）无声明；参与匹配但捕获空串的组照常登记。**与 `{词*}` 的引用权分工**：`?` 走普通命名组通路、三面引用（when/值校验/作用域接线）可用；`*` 走多值通路、三面禁区——次数轴 `+`/`*`/`?` 三档正交。**已知边界**：0+ 包裹重复组后接可选分隔（如 `[{标签*}]{ ?}{标题}`）时闭括号被收进可缺形态、左邻无必选字面锚，按位置约束拒绝（放宽是纯加法）。**两域缺席语义分叉**：模板域缺席=无绑定；手写 JSON 原生正则域（`RegexPattern.matchWithCaptures`，`rule_pattern.go:108-133`）沿用历史空串绑定，不改。
- **同占位词多次出现（位次分立）**：全部取值词（标签/作者/集名/标题/序号/作品号/日期/作品标识/描述 九词根）可在同一模板多次出现，裸写即可——按出现序（`tokenizeCondx` 从左到右，普通词/可选词位/重复段变体统一计数；多段目录模板按整条模板一次切流、自上而下跨段连续编号——`Artist[{标签}]/{标签}` 两处=第 1 处/第 2 处）自动编号，无新书写记号；`{标签2}` 仍是词表外报错、不解析为位次，`{公共段}`（及旧词 `{键}`）双出现维持「模板占位词 {词} 重复」拒绝。**位次=组名后缀与寻址键**：位1 保持裸组名（`tag`，存量单出现模板与旧档零变化），位 N≥2 组名=双下划线后缀（`tag__2`）；提取行 `captureName` 写位次名即取该位绑定（重复段位逐值扇出多声明），when 自有名与作用域接线限定名「成员ID.rN.组名」同样按位次名寻址，`#canon` 规范名键随位次名、位间不互扰。**三面禁引按位**：when 生效条件/值校验/作用域接线三面对位判定——位为重复段（多值产出）则该位禁引（引用取不到值=不成立/零产出，JSON 硬写报统一中文错误、文案按词根中文渲染），位为单值词（含可选词位）可引用。**值校验位次化**：值校验可挂位≥2（`occur` 字段；相等类别的对方词另有 `againstOccur`），位1 缺省=存量档案零变化。**位次漂移注意**：在已有出现之前插入同词根新出现（含跨段插段）会使后续位次整体 +1——旧 `tag__2` 仍存在但指向新插入处，存在性检查不报警、静默语义漂移，编辑模板后须复核引用了受影响位次名的提取/when/值校验/接线配置行。**与重复段记号正交**：多次出现 × 裸词/包裹/可选词位/重复段 `{词+}`/`{词*}`/`{词+;分隔}` 全组合合法、位次独立编号（`{标签}`×2+`{标签+}` 三处各自成位）。
- **填充段惰性化（2026-11-04 决策4）**：无类锚定的贪婪填充段（值类词 default `.+` 分支与中位 `{任意}` 吞位段）一律编译为惰性 `.+?`、让位一切占位词——leftmost-first 下惰性段取最短，后邻类词/重复段先取得满足位（`rule_condition.go:880-885`）；类锚定段不动（数字类/括号排除类/重复段位置组保持类内最大）。括号包裹的 `{任意}` 编译为排除配对闭括号的非空类（括号字面为锚、通配段不跨括号组吞并，前邻惰性 span 赖此收界）。存量切分语义允许变化（含 `_` 分隔模板首/尾段取舍、canon 载体切分），验收由 live-test diff 归因附记承载而非存量指纹不变闸。
- **快照求值器身份**：`RecognitionSnapshot.EvaluatorBuildID`（`recognition.go:989`，=自身插件清单 buildId，空串=未打标构建）铸入每份识别快照，参与两道闸——增量闸：mtime 游标复用须求值器身份等值（`recognition.go:3096-3100`）；激活对账：快照铸于另一构建标识的求值器即提示重新识别（`session.go:1070-1074`），未打标构建不参与比对、旧快照空串而当前有值按换版处理。buildId 内容化（`build.ps1`）：干净树=git describe，dirty 树附 dist 载荷摘要前 8 位——不同产物必不同身份，识别内核随构建演进后旧结论自动失去游标复用资格。

### 基目录刻画三式

一处目录若要被规则精确刻画为「基目录」，现有三式按代价递增：**多段目录模板**=层级写进格式（`Artist[{作者}]/{集名}`，`/` 紧邻、`//` 任意层、`/{N}` 显式层距，位置类信息的最简表达，覆盖「壳目录之下第二级=集名」这类实例）/ **父目录名锚**=既有谓词（parentFormat / parentContains，按名字锁定上级）/ **作用域附件**=复用别的规则认出的目录（目录行附加条件「位于此目录下」+层距，供给方独立成规则、改一处处处生效；来源也可取「库根」——层距即绝对层级：紧邻=根直下第 1 级、隔 N=自根数起第 N 级、任意=恒成立，补回 dirLevel 退役后的绝对层级表达）——仅当需要「复用他规则的目录结论」或自库根按绝对层级刻画时才需启用附件；位置与父名已能刻画基目录时不必等待附件。「基于其他条件」的条件间作用域仍是二期能力（主体锚预留槽保持、载入即拒，`rule_condition.go:168-178`），届时作同一附件的条件变体加法式接入。

## 本地导入工作台（骨架期）

- **创建入口三分支**（`work_fetch.go` `CreateWithHeartbeat`）：宿主新建任务输本地路径后——库根命中既有解析会话→意图信号「转入解析」零任务收尾；无会话→Create 流内弹「开始解析（默认）/取消」确认弹窗（等待期经 `HeartbeatCreateFetcher` 心跳保活，插件侧 5 分钟超时=取消，两态均以意图信号收尾，零任务零落库）；工作台发起的创建（会话带发起标记）→过滤产出分支（选择集过滤属后续阶段）。
- **会话管理器**（`session.go`）：会话=按库根持久化工件，三件套布局——meta 键 `workbench-session:<库根标识>` 值=信封 JSON `{v,session,shardSet,shards,codec,digest}`（轻字段+载荷簿记，shardSet 恒在场=新旧格式探测判据，schemaVersion 自管）；分片键 `workbench-session-snap:<库根标识>@{批次号}#{i}`，值=重载荷（Snapshot/LastDiff）gzip 压缩后的 base64 文本，单片最终值 ≤3MB；索引键 `workbench-session-index`=归一化库根升序数组（缺失/损坏回退全量扫描重建）；保存分轻/全双入口（唯一全保存入口=`CompleteRecognitionWithDiff` 识别完成落库，赋值/确认/选择集等会话级变更轻保存只写 meta、载荷留在分片），旧「单键单 JSON」格式兼容可读、读到即转新格式；同库根至多一活动会话，跨重启恢复；就地裁决不产规则、改写会话赋值（按文件+维度、信任级顶格、按维度覆盖压待裁决项；赋值为求值输入，重识别与增量轮不冲掉，清除赋值为唯一解除口）；档案写（泛化/规则编辑面两入口）与会话写一律经会话管理器单点串行；恢复会话时做规则档案与求值器身份对账（档案被外部变更、或快照铸于另一构建标识的求值器——快照带 `evaluatorBuildId` 字段——则提示重新识别；未打标构建〔标识空串〕不参与比对，旧快照空串而当前有值按换版处理）。
- **前端事件协议**：`plugin:local-import:workbench:{request|response|event}` 族，请求带序号配对（`frontend/src/workbench/` 入口 + `views/workbench/` 组件，经既有 Vite 预编译管线构建为多页面产物）。
- **页面声明**（`plugin.json`，契约 18）：`workbench` 一级页面（会话列表）+ 侧栏菜单 + `workbench-parse` 二级解析页面（`content.parent`；双栏工作区——左栏识别全景清单与筛选，右栏解析面板 `ParsePanel.vue` 承载单次赋值/泛化成规则/冲突裁决）+ 其两个子页（规则管理、解析观测〔「建设中」挂载位〕）+ 入口确认弹窗 dialog。解析视图头部另设「规则管理」「解析观测」直链。
